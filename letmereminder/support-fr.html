Questions fréquentes

Je ne reçois pas les rappels.
Vérifiez dans Réglages de l'iPhone, Notifications, LetMeRemind, que les notifications sont autorisées. Les notifications dépendent de votre iPhone et de ses réglages ; LetMeRemind ne remplace pas un agenda tenu pour vous.
Je change d'iPhone.
Si vous restaurez le nouvel iPhone depuis une sauvegarde de l'ancien, vos données suivent ; le verrouillage de l'app est à réactiver dans ses Réglages, car son code ne quitte pas l'ancien iPhone. Sinon, dans LetMeRemind, Réglages, Données, « Exporter un fichier chiffré », puis, sur le nouvel iPhone, « Importer un fichier », avec le même mot de passe.
Une notification montre le nom ou le montant.
Dans le rappel, activez « Sensible » : la notification dit seulement « Vous avez un rappel ». Un placement à terme est « Sensible » dès sa création. Le réglage d'iOS « Afficher les aperçus » (Réglages de l'iPhone, Notifications) masque aussi le contenu tant que l'iPhone est verrouillé.
Le montant d'un placement est masqué.
C'est voulu : rien ne se lit par-dessus l'épaule sans un geste. Dans Suivis et dans l'Agenda, les placements sont dans un groupe « Placements » replié : dépliez-le, puis touchez l'œil pour afficher les montants. Dans Finances, ils ont leur vue « Placements », floue tant que l'œil est fermé. L'œil se referme dès que vous quittez l'app. Sur l'Accueil et dans le Calendrier, le montant reste « ••• € » : ouvrez la fiche du placement pour le lire.
Mes placements ne comptent pas dans le budget.
C'est voulu aussi : ils sont tenus à part. Ils ne comptent ni dans les totaux ni sur le graphique du budget, et ont leur total et leur graphique dans Finances, vue « Placements ».
Je ne veux pas qu'on agisse depuis l'écran verrouillé.
Dans LetMeRemind, Réglages, Sécurité, activez « Déverrouiller pour agir depuis une notification » : « Payé », « Fait », « Vérifié » et « Reporter » demanderont d'abord de déverrouiller l'iPhone.
J'ai oublié le code de l'app.
Face ID ouvre l'app sans le code, sauf si les visages enregistrés dans Face ID ont changé : l'app demande alors son code une fois. Sans Face ID, le code ne peut pas être retrouvé : il n'existe pas de porte dérobée. C'est pourquoi un export chiffré régulier sert de sauvegarde : avec lui, vous pouvez réinstaller l'app et tout réimporter.
Pendant la bêta : comment signaler un problème ?
Faites une capture d'écran dans l'app : TestFlight propose de l'envoyer avec un commentaire, qui parvient au développeur par Apple. Après un plantage, TestFlight propose aussi d'envoyer un commentaire.

Ni compte, ni données chez le développeur

LetMeRemind n'a ni compte ni serveur : le développeur ne détient aucune de vos données, qui restent sur votre iPhone et dans ses sauvegardes. C'est aussi pourquoi un mot de passe d'export perdu ou un code de l'app oublié ne peuvent pas être retrouvés. Le détail est dans la politique de confidentialité.
